# 標注規則

第一版只標一種物件：`surfer`。

## Bounding box

- bbox 框人物身體，不把整張衝浪板納入框內。
- 身體被浪、板或其他人物遮住時，依可推定的人體範圍標注。
- 無法可靠判斷為人物時不要建立 bbox。

動作模型取 crop 時可以在 bbox 外增加背景範圍，讓模型看到衝浪板與浪；這不改變 bbox 標注規則。

## 動作

每一項都是獨立 checkbox，可以同時成立：

- `chasing_wave`／追浪
- `takeoff`／起乘
- `surfing`／衝浪

另有 `uncertain`／不確定。不確定的影格或片段保留 bbox，但不拿來訓練動作分類。

Label UI 鍵盤對應：

- `W`：追浪
- `E`：起乘
- `R`：衝浪

同一個框可以開啟多個狀態。只標部分 surfer 時，該影格仍可用於動作模型；只有明確勾選「所有 surfer 都已框完」的影格可用於 detector。

各動作的精確開始與結束條件，需在第一批影片試標後補上正反例。
